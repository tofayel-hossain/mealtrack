# MealTrack Management

A production-grade meal and expense management platform for shared flats, student hostels, and bachelor messes.

**Technology Stack**
- Frontend: React 19, TypeScript, Vite
- Routing: React Router v7
- Styling: Vanilla CSS
- Backend and Database: Supabase, PostgreSQL
- Authentication: Supabase Auth
- File Storage: Supabase Storage
- Security: PostgreSQL

**Core Features**
- Multi-mess management with invitations and role-based access
- Daily meal tracking, cooking status, and cutoff enforcement
- Bazar expense tracking with receipt uploads and personal grocery credits
- Member deposits and unified financial ledger
- Automated monthly meal rate and balance calculations
- Monthly closing, financial snapshots, and balance carry-forward
- Transparent member records and tamper-evident audit history
- Printable financial reports and CSV exports
- Secure manager transfer and auditable financial corrections

**Purpose:** Provide accurate, transparent, and reliable meal accounting for shared living communities.
